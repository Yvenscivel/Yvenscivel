## 👋 Sobre mim

Sou desenvolvedor backend com base em **Java e Spring Boot** e experiência prática em **agentes de IA, automação de processos e engenharia de dados**. Gosto de pegar um processo manual e lento e transformá-lo em um sistema confiável, com API, validação e monitoramento.

Estou concluindo **Ciência da Computação na UFC** e hoje trabalho de forma remota construindo pipelines de dados e agentes de IA para uso real, não só demos.

- 🧩 **Agora:** Data & Regulatory Intelligence Engineer na **RegDoor** (remoto, Reino Unido)
- ⚙️ **Também:** Desenvolvedor de Automação na **Jaguar Hub** e projetos de automação para PMEs
- 🔬 **Antes:** bolsista **PIBIC** em inteligência de dados na UFC
- 🌱 **Estudando:** FastAPI, Angular, RAG e arquitetura de agentes com MCP
- 🎯 **Aberto a oportunidades** em Backend Java e em Automação / Agentes de IA

## 💼 O que tenho feito

| | |
| :-- | :-- |
| 🏛️ **Pipeline de dados regulatórios** | Coleta automatizada de publicações regulatórias em dezenas de jurisdições, com n8n, Supabase/PostgreSQL e Airtable. Um segundo scraper com automação de browser por IA (Stagehand) valida tudo que o pipeline principal coleta. |
| 🤖 **Agentes e skills de IA** | Agentes com Claude Code e MCP que automatizam pesquisa regulatória: descoberta de fontes, rastreio de proposições legislativas e enriquecimento de contatos. |
| 💬 **Atendimento no WhatsApp** | Chatbots com n8n integrados a APIs REST. Na Jaguar Hub, a abertura de chamados urbanos ficou **~60% mais rápida**. Também desenvolvi um agente de agendamento com Gemini que reduziu o no-show em **~50%**. |
| 📊 **Pesquisa em dados (PIBIC)** | Pipelines em Python (Pandas, NumPy, Matplotlib) que derrubaram o tempo de entrega de relatórios de **5 dias para 2 horas**. |
